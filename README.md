# Smart Adaptive Traffic Light System (YOLO11 NCNN)
# نظام الإشارة المرورية الذكية التكيفية ومحاكي التقاطع الرباعي (MVP)

نظام إشارة مرور ذكية تكيفية في الوقت الفعلي ومحاكي تقاطع رباعي تفاعلي باستخدام نموذج **YOLO11n** المُصدّر بصيغة **NCNN** ومكتبة **OpenCV** ومحاكي ويب بتقنية **HTML5/Canvas**، مُحسّن للعمل بكفاءة وسرعة على الأجهزة ذات الموارد المحدودة مثل **Raspberry Pi 4**.

---

## 🚦 فكرة المشروع (Project Concept)

يهدف المشروع إلى معالجة مشكلة الازدحام المروري من خلال **التحكم الذكي والتكيفي في أزمنة إشارات المرور**:
1. **توحيد أصناف المركبات**: يتم رصد جميع أنواع المركبات (سيارات، شاحنات، حافلات، دراجات نارية) وتصنيفها تحت مسمى موحد: **"مركبة" (`Vehicle`)**، ويُعتمد **مجموع المركبات الإجمالي** كمقياس وحيد للكثافة المرورية في كل مسار.
2. **خوارزمية التوقيت التكيفي (Adaptive Signal Timing)**:
   - **تمديد وقت الإشارة الخضراء** للاتجاه الأكثر ازدحاماً لتخفيف الأزمة وتفريغ التقاطع (يصل حتى 40 ثانية).
   - **تقليل وقت الإشارة الخضراء عن الوقت الافتراضي** للاتجاه الخالي أو قليل السيارات إلى الحد الأدنى (5 ثوانٍ) لتجنب هدر وقت الانتظار على طريق سالك.
   - مرحلة صفراء انتقالية آمنة (3 ثوانٍ) قبل الانتقال التلقائي للاتجاه التالي.

## 🚀 محاور النظام (System Modules)

يتكون المشروع من نظامين متكاملين:

### 1️⃣ نظام الرصد المباشر بالكاميرا والفيديو (`traffic_counter.py`)
- استدلال وتتبع سريع للمركبات عبر نموذج `yolo11n_ncnn_model`.
- واجهة مراقبة بصرية (HUD) تتضمن إشارات مرور تفاعلية ثلاثية الألوان وعدادات تنازلية وشريط تقدم وبطاقة قرارات الذكاء الاصطناعي.
- **نمطان للتشغيل**:
  - **نمط التقاطع الافتراضي**: الإشارة 1 من الكاميرا/الفيديو المباشر، والإشارة 2 تمثل شارعاً متقاطعاً (مع إمكانية ضبط مركباته يدوياً بالأزرار `+` و `-`).
  - **نمط تقسيم المسارات (`Dual-Zone`)**: تقسيم شاشة الكاميرا لمسارين ورصد الإشارتين مباشرة من نفس الفيديو (يُفعل بالزر <kbd>Z</kbd>).

### 2️⃣ محاكي التقاطع الرباعي التفاعلي للويب (`web_simulator.py` + `smart_city/`)
- بيئة محاكاة واختبار مصممة وفق مجسم المدينة الذكية (**160cm × 120cm Miniature Smart City**)، مستندة إلى التقاطع الرباعي المركزي `N_AVE_J2` (Grand Avenue & Central Corridor).
- **الاتجاهات الأربعة (`+ Shape`)**:
  - ⬆️ **الشمال (North Corridor)**
  - ⬇️ **الجنوب (South Corridor)**
  - ⬅️ **الغرب (Grand Avenue West - ESP32-CAM Gantry)**
  - ➡️ **الشرق (Grand Avenue East - ESP32-CAM Gantry)**
- **سحب وإفلات وتغيير الصور (Drag & Drop)**: إمكانية رفع أو سحب أي صورة من جهازك لأي اتجاه، أو اختيار الصور الجاهزة، ويقوم نموذج YOLO فورياً بعدّ المركبات وضبط أزمنة الإشارات.
- **دورة إشارات تلقائية مستمرة (Auto-Cycle)**: دوران تلقائي وسلس بين الإشارات مع عداد تنازلي وأسهم حركة متوهجة على الإسفلت.
- **أزرار سيناريوهات سريعة (Presets)**:
  - 🔴 `North Jam`: ازدحام في الشمال (12 سيارة) لاختبار تمديد وقته فورياً.
  - 🟡 `Avenue Rush`: ازدحام على الشارع الرئيسي شرقاً وغرباً.
  - ⚪ `Empty Night`: تقاطع شبه خالٍ لتقليص أوقات الإشارات للحد الأدنى (5s).
  - 🟢 `Balanced`: حركة سير متوازنة.
- **تفعيل يدوي فوري**: إمكانية النقر على عنوان أي شارع لتحويل الإشارة الخضراء إليه فوراً.

## 🛠️ التثبيت والإعداد (Setup & Installation)

## ▶️ طرق التشغيل (Usage)

### 1. تشغيل نظام الكاميرا / الفيديو المباشر:
```bash
python traffic_counter.py
```
*(أو `./venv/bin/python traffic_counter.py`)*

#### اختصارات لوحة المفاتيح أثناء التشغيل:
| الزر | الوظيفة |
| :--- | :--- |
| <kbd>Space</kbd> | إيقاف مؤقت / استئناف الفيديو. |
| <kbd>+</kbd> / <kbd>=</kbd> | زيادة عدد مركبات الإشارة 2 في المحاكاة (لاختبار زيادة وقتها). |
| <kbd>-</kbd> / <kbd>_</kbd> | تقليل عدد مركبات الإشارة 2 في المحاكاة (لاختبار تقليل وقتها). |
| <kbd>Z</kbd> | التبديل بين نمط التقاطع الافتراضي ونمط تقسيم الكاميرا لمسارين (Dual-Zone). |
| <kbd>R</kbd> | إعادة ضبط دورة الإشارات لتبدأ من جديد. |
| <kbd>Q</kbd> | إغلاق البرنامج بأمان. |

---

### 2. تشغيل محاكي الويب التفاعلي للتقاطع الرباعي:
```bash
python web_simulator.py
```
ثم افتح المتصفح على الرابط:
👉 **`http://localhost:8080`**

- انتقل إلى تبويب **`AI Traffic Simulator`**.
- ستجد التقاطع الرباعي يعمل تلقائياً، ويمكنك سحب وإفلات أي صور واختبار الحالات المختلفة بنقرة واحدة!
