# Smart Adaptive Traffic Light System (YOLO11 NCNN)
# نظام الإشارة المرورية الذكية التكيفية (MVP)

نظام إشارة مرور ذكية تكيفية في الوقت الفعلي باستخدام نموذج **YOLO11n** المُصدّر بصيغة **NCNN** ومكتبة **OpenCV**، مُحسّن للعمل بكفاءة وسرعة على الأجهزة ذات الموارد المحدودة مثل **Raspberry Pi 4**.

---

## 🚦 فكرة المشروع (Project Concept)

يهدف المشروع إلى حل مشكلة الازدحام المروري من خلال **التحكم الذكي والتكيفي في توقيت إشارات المرور**:
1. **توحيد أصناف المركبات**: يتم رصد جميع أنواع المركبات (سيارة، شاحنة، حافلة، دراجة نارية) وتصنيفها تحت مسمى موحد: **"مركبة" (`Vehicle`)**، بحيث يُعتمد **مجموع المركبات الكلي** كمقياس رئيسي للكثافة المرورية.
2. **المقارنة التكيفية بين الإشارات**:
   - مقارنة أعداد المركبات بين اتجاهات التقاطع (إشارة 1 وإشارة 2).
   - **تمديد وقت الإشارة الخضراء** للإشارة الأكثر ازدحاماً لتخفيف الأزمة المرورية وتفريغ التقاطع.
   - **تقليل وقت الإشارة الخضراء عن الوقت الافتراضي** للإشارة الخالية أو الأقل ازدحاماً لتجنب هدر وقت الانتظار على طريق سالك.

---

## 🚀 المميزات الرئيسية (Features)

- **توحيد المسمى لكافة المركبات**: لا يتم تشتيت النظام بتفصيل كل نوع، بل تُعامل جميع المركبات كـ `Vehicle` ويُحسب مجموع المركبات المباشر.
- **خوارزمية التوقيت التكيفي (Adaptive Signal Timing)**:
  - **الوقت الافتراضي (`Default Green`)**: 15 ثانية.
  - **الحد الأدنى (`Min Green`)**: 5 ثوانٍ (عند خلو الطريق لتوفير الوقت).
  - **الحد الأقصى (`Max Green`)**: 40 ثانية (أثناء الازدحام الشديد).
  - **الإشارة الصفراء (`Yellow`)**: 3 ثوانٍ للمرحلة الانتقالية.
- **نمطان مرنان للتشغيل**:
  - **النمط الافتراضي (تقاطع طرق)**: إشارة 1 للكاميرا المباشرة / ملف الفيديو، وإشارة 2 لشارع متقاطع (يدعم التعديل اليدوي والمحاكاة التلقائية).
  - **نمط تقسيم المسارات (Dual-Zone)**: تقسيم شاشة الكاميرا إلى مسارين/إشارتين (إشارة 1 للمسار الأيسر، وإشارة 2 للمسار الأيمن) ورصدهما معاً عبر الكاميرا (يُفعل بالزر <kbd>Z</kbd>).
- **واجهة مراقبة بصرية متطورة (Interactive Traffic HUD)**:
  - مجسمات إشارات مرور رسومية ثلاثية الألوان (أحمر، أصفر، أخضر) بإضاءة متوهجة للحالة النشطة.
  - عداد تنازلي رقمي وشريط تقدم زمني لكل إشارة.
  - بطاقة قرار ذكية توضح سبب تمديد أو تقليل الوقت ووقت الانتظار الموفر.
  - ملصقات محددة على كل مركبة بمسمى موحد `Vehicle` وألوان مميزة لكل إشارة.
- **استدلال فائق السرعة عبر NCNN**: استهلاك منخفض للمعالج والذاكرة مناسب للأنظمة المدمجة.

## ▶️ التشغيل والتحكم (Usage & Controls)

لتشغيل نظام الإشارة الذكية:
```bash
python traffic_counter.py
```

### اختصارات لوحة المفاتيح أثناء التشغيل:
| الزر | الوظيفة |
| :--- | :--- |
| <kbd>Space</kbd> | إيقاف مؤقت / استئناف الفيديو. |
| <kbd>+</kbd> / <kbd>=</kbd> | زيادة عدد مركبات الإشارة 2 في المحاكاة (لاختبار زيادة وقتها). |
| <kbd>-</kbd> / <kbd>_</kbd> | تقليل عدد مركبات الإشارة 2 في المحاكاة (لاختبار تقليل وقتها للحد الأدنى). |
| <kbd>Z</kbd> | التبديل بين نمط التقاطع الافتراضي ونمط تقسيم الكاميرا لمسارين (Dual-Zone). |
| <kbd>R</kbd> | إعادة ضبط دورة الإشارات لتبدأ من جديد. |
| <kbd>Q</kbd> | إغلاق البرنامج وإنهاء التشغيل بأمان. |

### التبديل بين الكاميرا وملف الفيديو:
يمكنك تعديل المتغيرات في بداية ملف `traffic_counter.py`:
```python
USE_CAMERA = False          # اضبط على True لتشغيل الكاميرا المباشرة، أو False لملف الفيديو
VIDEO_PATH = "traffic.mp4"   # مسار ملف الفيديو المسجل
CAMERA_INDEX = 0            # رقم تعريف الكاميرا
```
